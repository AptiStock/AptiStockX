# Security Policy

## Reporting A Vulnerability

Please report security issues privately by email:

- support@aptistock.com

Do not open a public GitHub issue for vulnerabilities involving licensing, activation, payment flows, installer integrity, credential storage, or customer data.

## Official Downloads

Use only these official sources:

- https://aptistock.com/download
- https://github.com/AptiStock/AptiStockX/releases
- https://github.com/AptiStock/homebrew-tap

Verify installer checksums against `SHA256SUMS.txt`.
